### APEX-PARTNER-01 : KPI Cards Dashboard Partenaire ⭐

**Objectif** : Ajouter 4 KPI cards dans le dashboard partenaire (achats, ventes, lubrifiants, doléances).

#### Spécifications détaillées

**KPI 1 : Total achat carburant par produit (depuis début du mois)**
- Afficher le volume total de carburant acheté par type de produit (SP95, SP91, GO, Pétrole)
- Période : Du 1er du mois courant à aujourd'hui
- Unité : Litres
- Source : Table `achats_carburant` + `lignes_bc_carburant`
- Calcul : SUM(quantite_facturee) WHERE date_reception >= 1er du mois
- Affichage : Une card par type de carburant

**KPI 2 : Total ventes par produit depuis début du mois**
- Afficher le volume total de carburant vendu par type de produit
- Période : Du 1er du mois courant à aujourd'hui
- Unité : Litres
- Source : Table `shifts_carburant` + `lignes_shift_carburant`
- Calcul : SUM(volume) WHERE date_shift >= 1er du mois
- Affichage : Une card par type de carburant

**KPI 3 : Total Achat lubrifiants depuis début du mois**
- Afficher le volume total de lubrifiants achetés
- Période : Du 1er du mois courant à aujourd'hui
- Unité : Litres ou unité selon le produit
- Source : Table `achats_boutique` + `lignes_achat_boutique` (famille "Lubrifiants")
- Calcul : SUM(quantite) WHERE famille = 'Lubrifiants' AND date_achat >= 1er du mois
- Affichage : Une card avec le volume total

**KPI 4 : Doléances ouvertes**
- Afficher le nombre de doléances actuellement ouvertes
- Source : Table `doleances`
- Calcul : COUNT(*) WHERE statut IN ('envoyee', 'prise_en_charge')
- Affichage : Une card avec le nombre
- Code couleur : Orange si > 0, Vert si = 0

#### Implémentation

1. Créer `src/services/partnerKPIService.ts` :
   - `getAchatsCarburantMois(partenaireId, dateDebut)`
   - `getVentesCarburantMois(partenaireId, dateDebut)`
   - `getAchatsLubrifiantsMois(partenaireId, dateDebut)`
   - `getDoleancesOuvertes(partenaireId)`

2. Créer `src/components/partner/KPICards.tsx` :
   - Composant `KPICard` réutilisable
   - 4 instances pour les 4 KPIs
   - Utilisation de `useQuery` TanStack Query

3. Modifier `src/app/(partner)/partner/dashboard/page.tsx` :
   - Intégrer `KPICards` en haut du dashboard
   - Filtrer par partenaire connecté

**Tests** : unit service + e2e affichage KPIs
**Règle bible** : DIFF.md §1, Guide §12 (données opérationnelles uniquement)

### APEX-PARTNER-03 : Réalisation vs Objectif Mensuel + Projection ⭐

**Objectif** : Afficher pour chaque station la réalisation actuelle, l'objectif mensuel, le % de réalisation et une projection fin de mois.

#### Spécifications détaillées

**Affichage** : Tableau avec colonnes :
- Nom de la station
- Type de carburant
- Réalisation actuelle (litres) - depuis 1er du mois
- Objectif mensuel (litres)
- % de réalisation
- Projection fin de mois (litres)
- Écart vs objectif

**Calcul projection** :
- Jours écoulés = date actuelle - 1er du mois
- Jours restants = dernier jour du mois - date actuelle
- Vitesse journalière = réalisation actuelle / jours écoulés
- Projection = réalisation actuelle + (vitesse journalière × jours restants)

**Indicateur visuel** :
- % ≥ 100% : VERT
- 80-99% : ORANGE
- < 80% : ROUGE

**Source** : Table `objectifs` + `shifts_carburant`

#### Implémentation

1. Créer `src/services/partnerRealisationService.ts` :
   - `getRealisationsMensuelles(partenaireId, mois, annee)`
   - `calculerProjectionFinMois(realisation, dateActuelle)`
   - `getObjectifsMensuels(partenaireId, mois, annee)`

2. Créer `src/components/partner/RealisationObjectiveTable.tsx` :
   - Table avec calculs en temps réel
   - Indicateurs visuels

3. Intégrer dans dashboard

**Tests** : unit calcul projection + e2e affichage tableau
**Règle bible** : DIFF.md §3

### APEX-PARTNER-05 : Niveau Écarts Station ⭐

**Objectif** : Afficher le niveau des écarts de carburant pour chaque station avec tendance.

#### Spécifications détaillées

**Affichage** : Tableau avec colonnes :
- Nom de la station
- Type de carburant
- Écart total du mois (litres)
- Nombre d'écarts
- Écart moyen (litres)
- Tendance (amélioration / dégradation)

**Calcul** :
- Écart total = SUM(ecart) WHERE date_inventaire >= 1er du mois
- Nombre d'écarts = COUNT(*) WHERE date_inventaire >= 1er du mois
- Écart moyen = Écart total / Nombre d'écarts

**Indicateur visuel** :
- Écart positif : VERT
- Écart négatif < 5% : ORANGE
- Écart négatif ≥ 5% : ROUGE

**Source** : Table `inventaires_carburant`

#### Implémentation

2. Créer `src/components/partner/EcartLevelTable.tsx` :

**Objectif** : Afficher des statistiques détaillées sur les doléances incluant délai moyen par TM et délai global.

#### Spécifications détaillées

**Section 1 : Vue globale réseau**
- Nombre total de doléances ce mois
- Délai moyen de traitement réseau
- Délai moyen d'accusé de réception
- Délai moyen de résolution

**Section 2 : Vue par Territory Manager**
- Pour chaque TM :
  - Nombre de doléances assignées
  - Délai moyen d'accusé de réception
  - Délai moyen de résolution

**Calcul des délais** :
- Délai accusé réception = date_prise_en_charge - date_envoi
- Délai résolution = date_cloture - date_prise_en_charge
- Délai total = date_cloture - date_envoi

**Unité** : Heures ou jours

**Source** : Table `doleances` + `users` + `stations`

#### Implémentation

## CONCLUSION

Ce plan APEX-2 couvre toutes les nouvelles demandes du client documentées dans `guide/DIFF.md`. L'implémentation se fait en 3 phases :

1. **Phase 1** : Dashboard partenaire enhancé avec 8 APEX (KPIs, stocks, réalisations, écarts, doléances, filtre TM, dates)
2. **Phase 2** : Rapports partenaire détaillés avec 2 APEX (CA boutique, rapports par station)
3. **Phase 3** : Validation et tests avec 3 APEX (tests unitaires, tests E2E, validation)

Toutes les fonctionnalités respectent les règles fondamentales du Guide_Document_SuccessFuel.md :
- Le partenaire ne voit PAS les données financières
- Le partenaire voit uniquement les données opérationnelles
